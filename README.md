# 💰 Bankist App

A sleek and interactive modern banking interface built with vanilla **HTML**, **CSS**, and **JavaScript**. This project simulates a real-world banking experience, including login authentication, fund transfers, loan requests, account closure, and session management.

![Bankist UI](./Bankist-flowchart.png)

---

## 🚀 Features

- 🔐 **Login Authentication** with personalized welcome message
- 💸 **Balance Display** with formatted currency and dates
- 📈 **Dynamic Movements** (deposits/withdrawals) with sorting capability
- 🔁 **Money Transfers** between accounts
- 💵 **Loan Requesting** logic with eligibility check
- ❌ **Account Closure** after credential validation
- ⏱️ **Auto Logout Timer** for enhanced session security
- 🌐 **Locale-based Date & Currency formatting**

---

## 🛠 Tech Stack

- **HTML5** – Structure and layout
- **CSS3** – Responsive and modern styling
- **JavaScript (ES6+)** – Application logic and interactivity
- **Intl API** – For currency and date localization
